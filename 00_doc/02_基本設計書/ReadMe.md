## 1. 概要

### **目的：**

交通系 IC カードやスマートフォンの IC を用いて、本社扉の施錠・開錠を安全かつ効率的に管理する。本社の入退場をログに残して管理しセキュリティを向上させるため。

### **対象：**

本社出入口に設置されたスマートキー管理システム。

### **主要機能：**

1.  管理用 PC に IC カード／スマートフォンの IC 情報を登録
2.  NFC リーダーで登録済み IC の認証を実施
3.  認証成功時に Wi-Fi 経由で Sesame に開錠指示を送信し、一定時間後に自動施錠
4.  入場時や、退場時にログを残し本社の出入りをログに残す。

## 2. システム構成

### 2.1 ハードウェア構成

- IC カードリーダー(PaSoRi RC-S300) × 2
- スマートキー(SESAMI5)
- 延長台座
- WiFi モジュール(スマートキー用の中継器)
- 管理用 PC(Windows PC)
- ドアハンドル

### 2.2 ソフトウェア構成

- NFC 読み取りプログラム（Python）
- カードデータの管理用データベース（SQLite）
- IC カード管理システム（Python GUI アプリ flet）

## 3. 機能一覧

### 3.1 **SESAMI55 との通信**

1.  Wi-Fi モジュールを介した開錠/施錠コマンドの送信
2.  Sesame API を利用したステータス取得・操作
3.  一定時間後自動施錠
4.  外部と内部の二つカードリーダー管理
5.  入退室の記録

### 3.2 **ログ管理**

#### 1. 操作ログ

- 開錠・施錠の日時/状態
- 操作ユーザ（カード ID 紐付け）

#### 2. デバイス状態ログ

- バッテリー残量

#### 3. システムログ

- Sesame API の通信エラー
- アプリケーション例外（クラッシュ等）
- カードリーダー異常
- ログイン失敗
- Flet上でのページ遷移
- 登録カードの編集、削除

### 3.3 **電池容量の監視**

1.  Sesame 5 のバッテリー残量を定期監視
2.  残量低下時に自動メール通知

### 3.4 **カード管理（NFC）**

1.  登録済み IC カード情報の一覧表示・管理
2.  IC カードの新規登録および削除機能

### 3.5 **認証機能（NFC）**

1.  NFC リーダーで IC カードを読み取り、登録情報と照合
2.  認証成功時に Sesame5 の開錠コマンドを実行

## 5. システム運用

<!-- - ユーザーマニュアル
   ユーザーマニュアルでは、ユーザー登録、削除、管理を実現した。 -->

- 運用時間
  ドアの開閉のシステムのため、24 時間 365 日の運用を想定している。

- ログ管理
  エラーログは.log ファイルで残す方針。
  o2_src/my_app/logsのapp.logにアプリケーションのエラーログを、service.logにサービスログを残す。


- セキュリティ運用
  ログインできるアカウントとパスワードは、一つだけにして管理者で共用する。アカウントおよびパスワードはファイルで逐一変更できるものとする。ファイルの種類や変更の仕方はまだ未定。
