# ■ スマートキ解錠システムリポジトリ
スマートキー解錠システムの開発リポジトリです。  

## ディレクトリ
- 00_doc  
　⇒ドキュメント関係を格納
- 02_src  
　⇒ソースコードを格納
- 03_bin  
　⇒実行ファイルを格納(あれば)
- 04_data  
　⇒サンプルデータを格納(あれば)
- 98_work  
　⇒テストコード等を格納
- 99_tools  
　⇒環境構築に必要なTool等を格納

## ブランチ
- main  
　⇒releaseブランチ
- develop  
　⇒開発ブランチ
- develop_YYYY
