# logs ディレクトリについて

このディレクトリは、ドア開閉システムのログ管理に関する各種設定ファイルおよびログファイルを格納するためのものです。

## 構成

- `log_config_app.py`
  アプリケーション全体のロギング設定モジュールです。`import logs.log_config_app` でどこからでも利用できます。
  - ログは `app.log` に出力されます。

  - INFO以上のログがファイルに記録され、DEBUG以上のログがコンソールに表示されます。

- `log_config_service.py`
  サービス用のロギング設定モジュールです。`import logs.log_config_service` で利用できます。
  - ログは `service.log` に出力されます。

  - WARNING以上のログがファイルに記録され、DEBUG以上のログがコンソールに表示されます。

- `app.log`
  - アプリケーションの実行ログファイルです。

- `service.log`
  - サービスの実行ログファイルです。

- `__pycache__/`
  Pythonのバイトコードキャッシュディレクトリです。通常は手動で編集・削除する必要はありません。

## 注意事項

- ログ設定を変更したい場合は、各 `log_config_*.py` ファイルを編集してください。
- ログファイルは自動的にローテーションされますが、ディスク容量にご注意ください。
- 本ディレクトリ内のファイルはシステム運用上重要ですので、むやみに削除しないでください。
