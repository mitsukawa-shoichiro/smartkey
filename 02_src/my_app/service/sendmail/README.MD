## 📧 メール送信モジュール

- `sendmail_sys.py`
  このスクリプトは以下の2つの機能を1時間ごとに実行する Python モニタリングツールです：
  セサミスマートロックのバッテリー残量をチェックし、20%以下なら通知メールを送信
  ローカルAPIサーバーの生存チェックを行い、異常時に警告メールを送信

- `sendmail.py:`
  このモジュールは Python でメールを送信するためのシンプルな関数 `send_mail()` を提供します。  

---

## ✅ ファイル構成

- `sendmail.py`  
  メール送信の基本ロジックを実装。`send_mail(件名, 本文)` を呼び出すだけでメール送信が可能です。

- `sendmail_sys.py`  
  セサミのバッテリー残量とAPIサーバーの状態を定期的に監視し、異常時に自動でメール通知を行います。

---

## ✅ 使い方

### 1. 依存パッケージのインストール

```bash
pip install requests
```

### 2. 設定

- `sendmail.py` 内のメールアカウント情報（`mymail`, `mypass`, `to_mail` など）を自分の環境に合わせて設定してください。
- `sendmail_sys.py` 内の `sesame_id`, `x_api_key`, `url`, `sleep_time` も必要に応じて変更してください。

### 3. 実行方法

```bash
python sendmail_sys.py
```

1時間ごとに自動でバッテリーとサーバー状態をチェックし、必要に応じてメール通知します。

---

## ✅ メール通知内容

- バッテリーが20%以下の場合：「セサミ状態通知」
- サーバー異常時：「サーバー異常通知」

---

## ✅ 注意事項

- メール送信設定（SMTPサーバー、アカウント情報など）が正しいことを確認してください。
- セサミAPIやローカルAPIサーバーにアクセスできるネットワーク環境で実行してください。
- セキュリティのため、パスワードやAPIキーは環境変数や設定ファイルで管理することを推奨します。
