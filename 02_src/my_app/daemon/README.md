# daemonモジュールについて

## 概要
### カードリーダーを常時監視して読み取った値を適切な場所に送ります
このモジュールは一度起動したらバックシステムが止まるまで複数の並行処理をループし続けます。
動いてるスレッド(並行処理ループ)は読み取りループ、送信ループ、認証/登録受信ループの三本です。
主な動きは読み取りループがカード番号を検知、
認証なら送信用スレッドにキュー(同じプロセス内スレッド間での通信が可能な郵便箱)で送ります。(メモリ共有なので安全)
登録ならGUI側で待機しているスレッドにUDP送信(違うプロセス間での通信でも可能な伝書鳩)します。(ネットワーク通信を使わないと届かない)
また、GUI側から登録モードの連絡がきたときに読み取りループが登録用のスレッドに飛ばすようにグローバル変数を書き換える受信用スレッドもあります。

登録はGUI側での起動、終了の為常駐側では実装していません。

## 各関数について

### sender()
reader_loopから受け取ったキューの値からカード認証をする関数(card_sys.receive_card())に値を渡します。

### get_reader()
カードリーダー状態を確認する関数です。

### receiver()
状態の変更(認証/登録)を受け取ってreader_daemon内のグローバル変数を切り替える関数です

### send_message(message, host=HEARTBEAT_HOST, port=HEARTBEAT_PORT)
メッセージを実際に送る関数です。

### notify_registered_card()
reader_loopとsend_messageを橋渡ししている関数。

### reader_loop()
番号読み取りをループする関数です。
現在の状態が認証("authenticating")ならばsender()に対してevent_qを用いて値を渡し、登録("registering")ならばPORT:10001に対してUDP送信します。
受信はregister_listener.listen_loop()内sock.recvfrom(100)で受け取っています。

### changeState(newState)
更新された状態を実際に書き換える関数です。

### main()
起動用です、読み取りループ、状態受信、番号送信の三本のスレッドを起動します。
